# Attempt 041 curated publication

This directory describes the Git-published subset of the N24 unified
upstream-fault evidence-package experiment. Its existing terminal record
reports `completed_experiment_and_analysis`: 364 frozen packages, 1,092
completed reviews, 1,302 logical provider calls, and zero repair traces by
design.

## Included material

- the existing experiment freeze, live-consumption record, review and repair
  designs, package-exposure and pairwise-difference records, pre-live budget,
  semantic declarations, analysis, replay, and terminal records;
- seven captures, seven instances, seven disclosure catalogues, seven native
  group indexes, seven source bundles, 364 controller manifests, 364 reviewer
  packages, and all 1,092 completed review records;
- the 1,302 existing final provider response files associated with the recorded
  logical calls;
- qualification and reuse records, both terminal-incomplete history records,
  and the verifier, provider-schema, and legacy-schema correction records that
  precede successful closure;
- the N24 implementation, unified-review prompt, five response schemas, three
  focused test files, and the N20/N20A/N20D/N21 modules imported by the N24
  implementation;
- the three-part Attempt 041 findings report under
  `docs/workshops/n24-attempt-041-report-pack/`;
- previously committed Attempt 023, Attempt 026, Attempt 027, and Attempt 032
  publications, which remain unchanged.

## Excluded material

The complete local Attempt 041 directory is approximately 58 GB. Raw provider
requests and append-only ledgers, Codex homes and authentication databases,
dependency and plugin copies, caches, job stores, temporary directories,
duplicated evidence and workspaces, branch manifests, event streams, logs, and
other transient provider files are excluded. Only each selected provider
branch's final `output/response.json` is included from those branches.

Internal tasking and agent-coordination documents are not part of the public
experiment package. The two correction records retain their hashes and
scientific lineage without publishing those internal documents.

## Interpretation boundary

The six fault mechanisms are the independent faulty units; three reviewer
repetitions per condition are repeated model calls, not additional independent
faults. The compact graph package combines captured execution structure,
function identities, embedded source, values, and descriptions, so this
experiment does not isolate graph topology alone. A no-evidence reconsideration
pass matched or exceeded adaptive disclosure in several cells, so the results
do not establish a unique benefit from nested expansion.

This Git publication is not itself the anonymous ICLR review artifact. Any
double-blind supplementary ZIP must be produced separately without Git history,
author-identifying metadata, workstation paths, or links that reveal the
authors.
