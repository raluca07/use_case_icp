# Attempt 027 curated publication

This directory describes the Git-published subset of the downstream-first,
two-job Attempt 027. Its existing terminal record reports
`completed_experiment_and_analysis`: 64 frozen packages, 192 completed reviews,
and zero repair traces by design.

## Included material

- the existing experiment freeze, live-consumption, review design, empty repair
  design, qualification handoff, analysis, replay, and terminal records;
- four disclosure catalogues, 64 controller manifests, 64 reviewer packages,
  and all 192 completed review records;
- the 198 existing provider response files associated with the review calls;
- the N15 implementation and its focused test changes;
- the already tracked Attempt 023 and Attempt 026 artifacts on which this run
  records historical bindings.

## Excluded material

The complete local Attempt 027 directory is approximately 8.2 GB. Raw provider
requests and ledgers, Codex homes and authentication databases, caches, logs,
event streams, branch manifests, duplicated evidence, and other transient
provider-branch files are excluded. Only each selected provider branch's final
`output/response.json` is included from those branches.

Attempt 027 is a four-pipeline descriptive experiment with one upstream-fault
pipeline. Attempt 026 remains a separate direct-assigned-job pilot and is not
pooled into Attempt 027's reported analysis.
