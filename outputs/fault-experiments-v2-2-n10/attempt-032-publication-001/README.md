# Attempt 032 curated publication

This directory describes the Git-published subset of the downstream-first
Adaptive-versus-no-graph Attempt 032. Its existing terminal record reports
`completed_experiment_and_analysis`: 20 frozen packages, 60 completed reviews,
73 logical provider calls, and zero repair traces by design.

## Included material

- the existing experiment freeze, live-consumption, review design, empty repair
  design, qualification, analysis, replay, and terminal records;
- two captures, two instances, two disclosure catalogues, two source bundles,
  20 controller manifests, 20 reviewer packages, and all 60 review records;
- the 73 existing final provider response files associated with the recorded
  calls;
- the N16–N18 implementation, prompt, schemas, focused tests, complete findings,
  and overseer assessment whose hashes are bound by the Attempt 032 freeze;
- previously committed Attempt 023, Attempt 026, and Attempt 027 publications,
  which remain unchanged.

## Excluded material

The complete local Attempt 032 directory is approximately 3.2 GB. Raw provider
requests and ledgers, Codex homes and authentication databases, dependency and
plugin copies, job stores, temporary directories, duplicated workspaces,
prompt/schema evidence copies, branch manifests, event streams, logs, and other
transient provider files are excluded. Only each selected provider branch's
final `output/response.json` is included from those branches.

Attempt 032 is a descriptive experiment over one frozen upstream
`select_demand` fault pipeline and one matched clean control. Repeated reviews
do not establish performance across upstream fault classes. The strongest arm
combines nested Etiq evidence, embedded source/artifact content, and a mandatory
second review call; it does not isolate graph topology alone.
